# Porównanie struktur danych

Program porównuje czas dodawania i sortowania 100 000 losowych liczb dla tablicy, `vector`, kolejki FIFO, stosu LIFO, listy jednokierunkowej oraz drzewa binarnego.  
Dla każdej struktury mierzone są trzy operacje: dodanie pierwszych 100 000 elementów, sortowanie oraz dodanie kolejnych 100 000 elementów.  
Do pomiaru czasu wykorzystano bibliotekę `chrono`, a wyniki są wyświetlane w mikrosekundach.  
Program służy do porównania wydajności różnych struktur danych i sposobów ich sortowania.
