Porównywanie napisów



Program napisany w C++ porównuje dwie listy napisów wczytane z pliku a.txt. Następnie zapisuje raport w pliku b.txt, zawierający napisy wspólne oraz występujące tylko w jednej z list.



Program wykorzystuje wektory (vector<string>) do przechowywania danych oraz klasę checker, która odpowiada za wczytywanie, porównywanie i zapisywanie wyników.
