Program służy do tworzenia i obsługi drzewa binarnego wyszukiwania.

Lista:

pobieranie liczby elementów od użytkownika,

dodawanie podanych liczb do drzewa,

porównywanie wartości i umieszczanie ich po lewej lub prawej stronie,

przechodzenie drzewa metodą lewy → korzeń → prawy,

wyświetlanie wszystkich wartości w kolejności rosnącej.
